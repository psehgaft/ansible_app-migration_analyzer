== MTA 8.2 command map

[cols="1,1",options="header"]
|===
|Task |Command
|Show version |`mta-cli version`
|List providers |`mta-cli provider list`
|List sources |`mta-cli rules list-sources`
|List targets |`mta-cli rules list-targets`
|Test a ruleset |`mta-cli rules test <ruleset-path>`
|Analyze |`mta-cli analyze --input <path> --output <path> ...`
|Force container mode |Add `--run-local=false`
|Select C# provider |Add `--provider csharp`
|Replace output |Add `--overwrite`
|Help |`mta-cli <command> --help`
|===

== Required software

[cols="1,1,2",options="header"]
|===
|Software |Required version |Used for
|RHEL |8, 9, or 10 |Analysis host
|JDK |17 or later |MTA prerequisite and Java analysis
|Maven |3.9.9 or later |Java dependency/build analysis
|Podman/container-tools |RHEL-supported |C# and other containerized providers
|MTA CLI |8.2.0 in this guide |Analysis command line
|Python 3 and Ansible Core |RHEL-supported |Repository Visual Basic heuristic fallback
|===

== Final validation checklist

* [ ] RHEL release and architecture recorded.
* [ ] JDK 17+ and Maven 3.9.9+ validated.
* [ ] Rootless Podman validated.
* [ ] Red Hat registry login validated for container-mode runs.
* [ ] MTA version, providers, sources, and targets recorded.
* [ ] Java smoke analysis completed.
* [ ] C# ruleset selected and tested before C# analysis.
* [ ] Visual Basic scope and non-MTA provenance documented.
* [ ] Static report reviewed, checksummed, and stored under policy.
